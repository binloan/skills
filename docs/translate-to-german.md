# Translate to German

Install `translate-to-german` using the command in the [README](../README.md). Have Python 3 and subagent support available in your agent environment.

Give the skill pasted text or a DOCX, Markdown, plain text, or HTML file. It infers the source language and returns German text. For a file, it saves a copy with `-de` appended to the filename and provides a review of the translation.

You can specify the intended audience or preferred form of address when you supply the source.
